Put the two font files for the site in this folder (public/fonts):

1. AlteHaasGroteskBold.ttf
   Headings, wordmark, buttons, numbers.
   Download "Alte Haas Grotesk" by Yann Le Coroller (for example from dafont.com).
   Unzip it and copy ONLY "AlteHaasGroteskBold.ttf" here. Check the licence note on the download page.
   (Optional: convert it to AlteHaasGroteskBold.woff2 for faster loading; both names are supported.)

2. HelveticaNeue-Light.woff2
   Body text. Helvetica Neue is a paid font (Monotype / MyFonts / Linotype).
   Buy a web licence for "Helvetica Neue Light" (weight 300), download the .woff2 file,
   rename it to exactly "HelveticaNeue-Light.woff2" and put it here.
   Without it, Macs and iPhones still show Helvetica Neue (it's built in); other devices use Helvetica or Arial.

File names must match exactly (capital letters included). Then restart the app.
